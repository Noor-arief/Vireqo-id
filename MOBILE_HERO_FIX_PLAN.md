# Mobile Hero Fix Plan

Scope is intentionally limited to mobile hero presentation only.

- Do not change desktop/tablet layouts.
- Do not change copy/content.
- Do not change header/menu.
- Do not change BIMA, JavaScript, API, session logic, WhatsApp flow, DNS, SSL, or security hardening.
- Target only mobile hero typography and spacing: heading, paragraph, checklist, CTA.
- QA before any production deployment.
